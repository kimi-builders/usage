# Kimi Builders Usage 0.6.2

> [English](./RELEASE_NOTES_0.6.2.en.md)

## 本机扫描与模型价格

- 更新 Codex 持久化请求用量读取与去重，增加仅供本机分析的完整成功回合性能证据。
  回合耗时包含工具执行与等待，不代表纯模型生成速度；原始 ID 和性能样本不进入社区同步。
- 补齐 Cursor、OpenCode、MCode、Grok、DSH 和 ZCode 新日志格式及损坏记录处理；
  OpenCode 来源支持独立目录配置，异常来源不影响其他来源的可读事实。
- 更新十月模型价格目录与模型标识展示；价格详情明确上下文档位、缓存写入 TTL、
  临时价格和未定价数据。API 等价价值仍是估算，不是订阅账单或实际节省。
- 增加扫描 benchmark 命令，输出时间与内存指标，不上传日志。

## 账号与官方权益

- Kimi Code 支持一个本机 CLI 登录和多个独立 Coding API Key 账号，兼容新版额度响应。
  凭据、申报订阅信息和历史按连接隔离；仅展示接口返回的窗口，不虚构周额度。
  已验证的共享额度所有者使用本机盐化身份去重，无法证明归属时不关联本机 Token。
- OpenCode Go 增加明确的本机登录模式；手动账号缺少凭据时不会借用其他登录。
- WorkBuddy 增加主动提供 Cookie + User-Agent 的官网 Credits 查询；不读取浏览器登录。
  Credits、预留量和周期结束时间不换算 Token。
- 补齐 Claude 重置券、促销云 Credits 和可验证的续费/到期事实，以及 JetBrains
  本机日志额度读取。可选元数据失败不会隐藏已有有效额度。
- 优化账号设置与保存反馈，保留未保存草稿，清理已提交的凭据草稿，避免陈旧设置覆盖新连接。

## 看板与发布质量

- 统一 Inter 字体、蓝色强调色、点阵纹理和图表层级动画；保留系统字体回退和减少动画偏好。
- Inter 仅打包三种字重的 Latin / Latin-ext WOFF2，避免重复格式与无关脚本字体；
  修复里程碑庆祝提示底色，增加字体产物和背景声明回归检查。
- 继续保留本机观测、官方权益、派生估算与用户申报目标的独立口径。
  本轮不扩大社区同步字段或默认来源权限。

## 升级

```bash
npx @kimi.builders/usage@latest dashboard
```

已安装后台同步的用户可在看板选择“更新到当前版本”，或执行：

```bash
npx @kimi.builders/usage@latest daemon restart
```

升级保留本机历史、配置和社区连接。新增额度 Provider 均需用户主动配置；
本机用量扫描不依赖这些凭据或在线查询。
