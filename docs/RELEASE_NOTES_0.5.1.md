# Kimi Builders Usage 0.5.1

> [English](./RELEASE_NOTES_0.5.1.en.md)

`0.5.1` 是本地看板的展示、定价和订阅额度兼容性更新，并让公开项目文档完整提供中英文版本。

## 用量展示与海报

- 中文界面统一使用本地化紧凑数字，例如 `26.2亿`、`160万` 和 `48.1万`；英文继续使用
  K/M/B。用量中心、图表、明细、权益中心和分享海报保持同一口径。
- “分享战绩”更名为“分享用量”；英文海报恢复独立英文文案，不再误用中文标签。
- 对 Token、请求数和用户消息数补充对应语言与单位测试，避免两种语言再次漂移。

## 模型价格

- 更新本地标准 API 价格目录，补充 Grok 4.5、GPT 5.6 Luna、GLM、Kimi、MiMo、MiniMax、
  Qwen、DeepSeek 和 Hy3 等模型与上下文档位。
- 价格仍按生效时间、上下文档位和处理档位匹配；未匹配 Token 继续标记为未定价，不按 0 美元处理。

## 订阅额度兼容性

- GitHub Copilot 改用明确的设备授权流程，支持多个账户并分别保存额度历史。
- OpenCode Go 按真实账户模型保存多个 Cookie，自动发现 Workspace，并允许为单个账户提供
  可选 `wrk_…` 覆盖值；设置界面不再要求用户把多个账户挤进一组字段。
- 改进额度历史的账户归属、查询并发和 Provider 级失败隔离。
- 移除已经无法稳定验证的 Windsurf/Devin 额度集成，避免展示猜测或持续失败的数据。

## 文档与语言

- README 的 Agent 代办提示词跟随文档语言：中文版使用中文指令，英文版使用英文指令。
- 除 LICENSE 和 NOTICE 外，所有公开用户/维护文档都提供可互相切换的中文与英文版本。
- 更新文档索引、路线图、兼容矩阵、网络与隐私说明，使它们与 `0.5.1` 行为一致。

## 升级

```bash
npx @kimi.builders/usage@latest dashboard
```

已安装后台同步的用户应刷新调度器记录的包路径：

```bash
npx @kimi.builders/usage@latest daemon restart
```

升级不会改变已选择的扫描/同步范围，也不会删除本地历史、社区连接、Provider 账户或远端数据。
