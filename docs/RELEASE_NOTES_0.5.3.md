# Kimi Builders Usage 0.5.3

> [English](./RELEASE_NOTES_0.5.3.en.md)

`0.5.3` 重构权益中心的信息层级与 Provider 覆盖，并修复 Kimi Code 本机登录态过期后
必须手动执行 `/status` 才能恢复额度查询的问题。所有额度读取与 Token 分析仍在本机完成，
社区同步范围没有扩大。

## 权益总览与账号页

- 权益中心总览保留已连接权益、个人付费、非付费权益、本机 Token 与官方事实覆盖等顶部摘要，
  并新增即将重置、5 小时窗口、每周窗口和账户重置进度。
- 新增独立“账号”页，集中展示单账号的官方额度/余额、订阅事实、本机观测 Token、容量估计、
  证据来源和官方用量中心入口，避免总览与明细重复。
- 5H 与每周窗口可切换查看；不同周期不相加，官方额度事实、本机观测与派生估计继续分开标识。
- 用量中心默认范围改为“今天”；权益明细分页现在按真实记录数计算，不再固定显示四页。

## Provider 与登录可靠性

- 新增 Antigravity 本机额度读取与 Gemini/Claude/GPT 模型窗口；移除已经停止个人服务的
  Gemini Code Assist 额度 Provider。Gemini CLI 历史用量解析器仍保留。
- 新增 DeepSeek 官方余额查询，并把本机 DeepSeek 模型用量关联到同一账号分析视图。
- Kimi Code 在访问令牌过期时会使用本机 OAuth 刷新令牌自动换取新令牌，并原子更新本机凭据；
  无需先在终端执行 `/status`。缺失或失效的刷新令牌仍会返回可操作的重新登录提示。
- 更新 Provider contract、安全边界、网络目标、隐私文档与失败隔离测试。

## 文案、可视化与 README

- 统一中英文权益术语、5 小时滚动（5H 频限）和每周周期表达，修复英文界面夹杂中文的问题。
- 优化趋势图、Token 归因摘要、权益容量卡片、海报和跨尺寸布局。
- README 的总览、趋势、权益中心及 24H/30D 海报全部换成当前版本截图，并为中英文文档分别提供本地化图片。

## 升级

```bash
npx @kimi.builders/usage@latest dashboard
```

已安装后台同步的用户应刷新调度器记录的包路径：

```bash
npx @kimi.builders/usage@latest daemon restart
```

升级不会删除本地历史、社区连接、Provider 账号、凭据或远端数据。
