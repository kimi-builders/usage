# Kimi Builders Usage 0.5.2

> [English](./RELEASE_NOTES_0.5.2.en.md)

`0.5.2` 重点打磨本地 Dashboard 的视觉选择、权益设置稳定性与 OpenCode Go 多账户模型，
不改变用户已经选择的本机扫描和社区同步范围。

## 看板视觉与交互

- 新增可持久化的 Vibe 视觉风格切换，同时保留原有深浅主题和语言设置。
- 统一侧栏、筛选器、弹窗、权益卡片和小屏布局的状态与尺寸，修复长弹窗内容溢出、操作区
  被遮挡以及展开卡片破坏网格的问题。
- 弹窗不再因误点遮罩层直接关闭；存在未保存修改时，关闭按钮和 Escape 都会先确认。
- 权益设置拆分为独立组件，并补充无效本地设置的容错，避免旧配置导致 Dashboard 崩溃。

## OpenCode Go 账户权益

- OpenCode Go 的账户名称、Cookie、`wrk_…` Workspace ID、权益类型、实际价格、货币、账期和
  续费日现在作为一套不可拆分的账户配置保存。
- 每个账户必须具备完整且有效的连接信息后才会查询额度；新增账户不会复用其他账户的
  Workspace 或订阅信息。
- 旧版供应商级订阅信息只迁移到此前激活的账户一次，防止多账户重复计费。
- 权益总览按 OpenCode Go 账户分别统计权益类型和实际月费，但本机 Token 仍按 Agent 来源
  只计算一次，避免无法归属到具体账户的日志被重复放大。

## 保存与刷新体验

- “保存并刷新额度”会保存设置、刷新额度并保留弹窗，方便继续检查其他账户。
- “保存并关闭”会保存、刷新并返回权益中心；成功或失败信息显示在操作附近。
- 改进凭据脏状态识别、字段级校验和 Provider 失败定位，已保存的 Cookie 不会在刷新后被误判为缺失。

## 升级

```bash
npx @kimi.builders/usage@latest dashboard
```

已安装后台同步的用户应刷新调度器记录的包路径：

```bash
npx @kimi.builders/usage@latest daemon restart
```

升级不会删除本地历史、社区连接、Provider 账户、凭据或远端数据。
